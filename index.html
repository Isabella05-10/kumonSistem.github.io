Visão Geral do Projeto

O projeto propõe o desenvolvimento de um sistema web para centralizar e facilitar a gestão de uma unidade Kumon. A proposta busca melhorar a organização dos dados de alunos e responsáveis, o cadastro de matrículas, o controle de documentos e o acompanhamento das solicitações. Dessa forma, o sistema pretende reduzir a dificuldade de gerenciar informações e tornar os processos administrativos mais organizados. O projeto utiliza conceitos de Estrutura de Dados e Teoria da Computação para fundamentar suas decisões técnicas.

Estado Atual de Desenvolvimento

Até o momento, foi desenvolvido o planejamento do sistema e um protótipo visual para representar sua estrutura e funcionamento. O protótipo apresenta a página inicial, o formulário de matrícula, a tela de login, o painel do responsável, o painel administrativo e o fluxo de matrículas. Como próximos passos, estão previstos o desenvolvimento das funcionalidades, a integração com o banco de dados e a realização de testes.

Teoria da Computação

A Teoria da Computação pode ser aplicada na validação dos dados inseridos no sistema. Expressões regulares ajudam a verificar se informações seguem um formato esperado, como um endereço de e-mail. Já os Autômatos Finitos Determinísticos (AFD) reconhecem linguagens regulares, aceitando ou rejeitando sequências de caracteres conforme as regras definidas.

Estruturas de Dados

As listas permitem armazenar e organizar os dados dos alunos, facilitando a inclusão e a consulta dos registros. As filas podem controlar as solicitações de matrícula por ordem de chegada, seguindo o princípio FIFO (primeiro a entrar, primeiro a sair). As pilhas podem auxiliar no controle de operações recentes, seguindo o princípio LIFO (último a entrar, primeiro a sair). Já as tabelas hash permitem localizar alunos por identificadores, tornando as buscas mais rápidas. Cada estrutura possui vantagens diferentes, e sua escolha depende da operação que o sistema precisa realizar.

Lista

Organização dos registros dos alunos, permitindo adicionar e consultar informações.

Fila (FIFO)

Organização das solicitações de matrícula por ordem de chegada.

Pilha (LIFO)

Controle de operações recentes, facilitando o acesso à última ação realizada.

Tabela Hash

Localização de alunos por meio de identificadores, agilizando as consultas.

Complexidade Computacional

A notação Big-O permite analisar como o tempo de execução de um algoritmo cresce conforme aumenta a quantidade de dados. Por exemplo, uma busca sequencial em uma lista possui complexidade O(n), pois pode precisar verificar todos os elementos. Já uma busca em tabela hash pode apresentar complexidade média O(1). Os conceitos de P e NP ajudam a compreender os limites de eficiência na resolução de problemas computacionais.

Busca Sequencial

O(n)

Pode verificar os elementos um por um até encontrar o aluno desejado.

Busca em Tabela Hash

O(1) médio

Permite localizar registros rapidamente utilizando identificadores.

Ordenação e Busca

A ordenação permite organizar os registros dos alunos, facilitando a consulta das informações. Algoritmos como Bubble Sort e Insertion Sort podem ser utilizados para ordenar os dados. Já a busca binária permite localizar registros com mais eficiência quando os dados estão previamente ordenados. A escolha do algoritmo considera a quantidade de informações e o desempenho esperado.

Bubble Sort

Pode organizar os registros dos alunos, comparando elementos vizinhos e trocando suas posições quando necessário.

Busca Binária

Pode localizar um aluno pelo identificador em uma lista previamente ordenada, reduzindo a quantidade de comparações.

Insertion Sort

Organiza os registros inserindo cada elemento na posição correta em relação aos anteriores, mantendo os dados ordenados.

Memória e Alocação

Durante a execução do sistema, os dados precisam ser armazenados e acessados na memória. Em linguagens como C, ponteiros permitem acessar endereços de memória, enquanto funções como malloc e free possibilitam reservar e liberar espaços dinamicamente. Esses conceitos ajudam a compreender a importância do uso eficiente da memória e evitam desperdícios durante o processamento das informações.

Alocação Dinâmica

Permite reservar espaço na memória conforme a necessidade do sistema, utilizando funções como malloc.

Liberação de Memória

A função free libera espaços que não são mais necessários, contribuindo para um melhor aproveitamento da memória.

Decisões de Engenharia

A arquitetura do sistema considera o tipo de operação realizada com os dados. Para cadastrar e consultar alunos, podem ser utilizadas listas e tabelas hash. Para organizar as solicitações de matrícula, as filas permitem respeitar a ordem de chegada. Além disso, a análise da complexidade Big-O ajuda a comparar o desempenho das operações. Essas decisões buscam equilibrar a velocidade de consulta, a facilidade de inserção de dados e o uso da memória, contribuindo para um sistema mais organizado e eficiente.

Organização dos Alunos

Listas permitem organizar os registros, enquanto tabelas hash podem agilizar a localização por identificadores.

Controle de Matrículas

Filas permitem processar as solicitações por ordem de chegada, mantendo uma sequência organizada.

Desempenho

A análise Big-O ajuda a avaliar o custo das operações e comparar diferentes soluções.

Conclusão

O desenvolvimento deste projeto demonstra como os conceitos de Teoria da Computação e Estrutura de Dados contribuem para a construção de sistemas organizados e eficientes. Durante o planejamento do sistema da unidade Kumon, esses conhecimentos ajudaram a identificar estruturas adequadas para organizar os alunos, controlar as solicitações de matrícula e melhorar as consultas de informações. Além disso, os estudos sobre complexidade e gerenciamento de memória permitem compreender como tomar decisões que favoreçam o desempenho do sistema. Dessa forma, a disciplina oferece uma base teórica importante para as próximas etapas de desenvolvimento do projeto.
